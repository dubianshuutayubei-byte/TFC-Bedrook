# Survival HUD 実装メモ

更新日：2026-11-28

## 現在の実装

- Script API の `Player.onScreenDisplay.setActionBar` を利用した簡易HUD。
- 表示内容：TFC表記、年、季節、年内日数。
- 40 tick（約2秒）ごとにオンラインプレイヤーへ更新。
- プレイヤー初回スポーン時にも即時表示。
- バニラHUDの表示・配置は変更しない。
- HUD文字列生成は純粋関数として分離し、Nodeテストで検証。

## 重要な制約

Action BarはMinecraftの共有表示領域であり、他アドオンが同じ領域へ書き込むと表示が競合する可能性がある。現段階ではHUDの最小実装として採用し、後に専用UI JSONや設定可能な表示方式を検討する。

水分・栄養・体温はライブのプレイヤー状態と永続化がまだ接続されていないため、数値を捏造して表示しない。各Needsシステムのランタイム接続後に追加する。
