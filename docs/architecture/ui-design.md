# TFC-Bedrook UI設計・初期実装

更新日：2026-11-28

## 1. UI方針

- UIはゲーム内で完結させ、日本語を標準にする。
- ナッピング、鍛冶、鋳造、容器管理など、操作が複雑な工程は専用UIを用意する。
- UIを開いていないプレイヤーに定期的なUI処理を実行しない。
- UI表示値は保存データから取得し、表示用の値を別に保存しない。
- 未実装の数値を0や仮値で表示しない。
- 操作中のプレイヤーを識別し、マルチプレイで他人の入力が混ざらないようにする。
- UIのキャンセル・閉じる操作でアイテムや設備状態が失われないようにする。

## 2. 初期メニュー

現時点の初期メニューは `@minecraft/server-ui` の安定版ActionFormDataを使用する。

- フィールドガイド
- プレイヤー情報
- システム一覧
- 閉じる

フィールドガイドは序盤進行、地質・気候、金属加工、農業・食品、動物・畜産、食品保存のカテゴリへ分岐する。

## 3. 操作UIの実装予定

| UI | 主な操作 | データ連携 |
|---|---|---|
| ナッピング | 石器形状・パターン選択 | 入力素材、完成形、失敗判定 |
| 陶器成形 | 型・成形パターン選択 | 粘土、未焼成品 |
| Pit Kiln | 投入物・燃料・焼成開始 | 熱、燃料、処理進行 |
| 金属鋳造 | 型選択、溶融金属の注入 | 金属種、量、温度 |
| Crucible | 複数金属の投入、合金確認、排出 | 合金比率、溶融量 |
| Anvil | Plan、Target、Action選択 | 金属温度、加工履歴、Tier |
| 食品・保存 | 調理、乾燥、塩漬け、燻製、密封 | 食品状態、腐敗時計、保存素材 |
| 燻製設備 | 燻製レシピ開始 | 隣接焚き火の燃焼/温度、肉、落ち葉 |
| 農地 | 土壌水分・N/P/K確認 | Crop、Climate、Soil |
| 容器 | 内容物の出し入れ | サイズ、重量、容量、腐敗 |

## 4. 初期アクセス方法

開発中のテスト用に、プレイヤーが次のコマンドを実行するとメインメニューを開く。

`/scriptevent tfc:menu`

製品版では専用ガイドアイテムまたはゲーム内の自然な操作導線に置き換える。コマンドは開発用の入口であり、完成版の唯一の操作方法にはしない。

## 5. APIバージョン

Minecraft Bedrock 26.60を対象に、次の安定版依存を使用する。

- `@minecraft/server`: `2.11.0`
- `@minecraft/server-ui`: `2.3.0`

Beta UI APIは初期メニューには使用しない。安定版で実装できない操作が明確になった場合のみ、個別にBeta APIを評価する。

## 6. 現在のUI実装状況

- ナッピング：5×5（25マス）の位置選択UI。選択状態の表示・解除に対応。ただし現在の完成判定は仮パターンであり、TFC準拠の道具別パターン/除去マス判定は未完了。
- 加工設備：設備状態、燃料残量、温度、レシピ材料・出力、加工進捗をActionFormDataで表示。金床の冷却操作も接続。燻製設備は隣接する燃焼中の焚き火が80°C以上であることを開始条件として表示/判定。
- 農地：土壌タイプ、肥沃度、気温、水分、N/P/Kを表示し、種まき・肥料投入を操作可能。
- 動物：空手で調べると専用フォームに性別、年齢/成熟目安、空腹、渇き、健康、なつき度、妊娠状態を表示。餌や空き瓶による操作は従来どおり手持ちアイテムで行う。
- 食品：鮮度は腐敗処理と摂取判定に接続済み。メインメニューの「食品鮮度一覧」から、インベントリ内の食品をスタック単位で個別表示（スロット、個数、鮮度率、鮮度段階）。粘土封印具で容器を封印/開封した際も格納食品の鮮度一覧を表示。
- 全UIは日本語。端末実機での表示サイズ、ボタン配置、同時操作の確認は未実施。

## 8. 追加操作UI（2026-11-28）

- 陶器成形は粘土玉をスニーク+使用して開く。成形UIから土器、インゴット鋳型、るつぼを選択し、必要数を消費して未焼成品を得る。るつぼはPit Kilnで焼成後、石レンガと組み合わせて設備化する。
- Crucibleは設備を操作して金属を1個ずつ投入。配合比を画面で確認し、青銅の組成範囲・温度・焼成鋳型の条件を満たした場合のみ鋳造する。投入中の金属量は設備位置単位でDynamic Propertyへ保存。鉱石鋳造・合金比率・必要温度・出力は共通の加工レシピ定義を参照し、UI側との二重定義を避ける。
- 食品を手に持ってスニーク+使用すると鮮度の個別画面を開く。通常使用/摂取は従来の操作を維持する設計だが、実機イベント競合は未確認。
- 乾燥棚は個別作物の乾燥レシピに加え、生肉と塩から塩漬け肉を作る。海洋Biomeの水源から海水入り土器を採取し、焚き火で塩を抽出する。燻製設備は落ち葉と生肉を使い、隣接する燃焼中の焚き火（80°C以上）を条件に燻製肉を作る。瓶詰め・冷蔵は未実装。
- これらはコード/Nodeテストで検証する範囲。Bedrock 26.60の実機でUI操作、Dynamic Property永続化、同時アクセスを検証する必要がある。


## 9. 食品保存・陶器拡張（2026-11-28）

- 塩漬け肉・燻製肉を食品アイテムとして登録し、鮮度減少速度と栄養値を設定。値は暫定バランス。
- 海水入り土器から焚き火で塩を抽出し、塩と生肉を乾燥棚で塩漬け肉へ加工。
- 燻製設備は隣接/直下の燃焼中焚き火が80°C以上のときだけ加工開始できる。生肉と落ち葉から燻製肉を作る。
- 土器4個、インゴット鋳型8個、るつぼ8個の粘土玉コストを成形UIと整合。未焼成るつぼ→Pit Kiln焼成→石レンガと組み合わせてるつぼ設備、の工程を追加。
- 26.60実機でのBiome判定、UI、温度、加工完了、マルチプレイは未検証。
