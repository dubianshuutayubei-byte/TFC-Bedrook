# TFC-Bedrook UI設計・初期実装

更新日：2026-11-28

## 1. UI方針

- UIはゲーム内で完結させ、日本語を標準にする。
- ナッピング、鍛冶、鋳造、容器管理など、操作が複雑な工程は専用UIを用意する。
- UIを開いていないプレイヤーに定期的なUI処理を実行しない。
- UI表示値は保存データから取得し、表示用の値を別に保存しない。
- 未実装の数値を0や仮値で表示しない。
- 操作中のプレイヤーを識別し、マルチプレイで他人の入力が混ざらないようにする。
- UIのキャンセル・閉じる操作でアイテムや設備状態が失われないようにする。

## 2. 初期メニュー

現時点の初期メニューは `@minecraft/server-ui` の安定版ActionFormDataを使用する。

- フィールドガイド
- プレイヤー情報
- システム一覧
- 閉じる

フィールドガイドは序盤進行、地質・気候、金属加工、農業・食品、動物・畜産のカテゴリへ分岐する。

## 3. 操作UIの実装予定

| UI | 主な操作 | データ連携 |
|---|---|---|
| ナッピング | 石器形状・パターン選択 | 入力素材、完成形、失敗判定 |
| 陶器成形 | 型・成形パターン選択 | 粘土、未焼成品 |
| Pit Kiln | 投入物・燃料・焼成開始 | 熱、燃料、処理進行 |
| 金属鋳造 | 型選択、溶融金属の注入 | 金属種、量、温度 |
| Crucible | 複数金属の投入、合金確認、排出 | 合金比率、溶融量 |
| Anvil | Plan、Target、Action選択 | 金属温度、加工履歴、Tier |
| 食品・保存 | 調理、塩漬け、密封 | 食品状態、腐敗時計 |
| 農地 | 土壌水分・N/P/K確認 | Crop、Climate、Soil |
| 容器 | 内容物の出し入れ | サイズ、重量、容量、腐敗 |

## 4. 初期アクセス方法

開発中のテスト用に、プレイヤーが次のコマンドを実行するとメインメニューを開く。

`/scriptevent tfc:menu`

製品版では専用ガイドアイテムまたはゲーム内の自然な操作導線に置き換える。コマンドは開発用の入口であり、完成版の唯一の操作方法にはしない。

## 5. APIバージョン

Minecraft Bedrock 26.60を対象に、次の安定版依存を使用する。

- `@minecraft/server`: `2.11.0`
- `@minecraft/server-ui`: `2.3.0`

Beta UI APIは初期メニューには使用しない。安定版で実装できない操作が明確になった場合のみ、個別にBeta APIを評価する。

## 6. 現在のUI実装状況

- ナッピング：3×3の位置選択を表示し、選択済み位置の状態と解除操作を案内する。解答パターンは画面に表示しない。
- 加工設備：設備状態、燃料残量、温度、レシピ材料・出力、加工進捗をActionFormDataで表示。金床の冷却操作も接続。
- 農地：土壌タイプ、肥沃度、気温、水分、N/P/Kを表示し、種まき・肥料投入を操作可能。
- 動物：空手で調べると専用フォームに性別、年齢/成熟目安、空腹、渇き、健康、なつき度、妊娠状態を表示。餌や空き瓶による操作は従来どおり手持ちアイテムで行う。
- 食品：鮮度は腐敗処理と摂取判定に接続済みだが、食品個体の詳細確認・保存方法選択UIは未完了。
- 全UIは日本語。端末実機での表示サイズ、ボタン配置、同時操作の確認は未実施。
