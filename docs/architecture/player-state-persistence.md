# Player State 保存実装

## 目的
TFCのプレイヤー個人データを、ワールド再起動後も保持できるようにする。

## 保存方式
- 保存先：Player Dynamic Properties
- キー：`tfcb:player_state`
- 形式：小さなversion付きJSON文字列
- schema version：1
- 初期水分：100 / 100
- 栄養カテゴリ：grain / fruit / vegetables / protein / dairy（各0〜100）
- 不正値・欠損値は安全な範囲へ正規化する。

## 現在の接続範囲
- 初回スポーン時にロード。
- 新規データ・旧バージョン・破損JSONは正規化して保存。
- ロードした水分をHUDに表示。
- プレイヤー退出時にメモリ上のキャッシュを破棄。
- 食事・飲水による値の変化はまだ未接続。現在の数値は保存基盤の初期値であり、実際の飲食処理が完了したという意味ではない。

## 検証
Node.js単体テストで初期化、正規化、シリアライズ、破損データ、値更新を検証する。
Bedrock実機での再参加・ワールド再起動後の保持確認は未実施。
