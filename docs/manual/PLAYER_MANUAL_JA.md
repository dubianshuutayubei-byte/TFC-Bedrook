> 対象：Minecraft Bedrock Edition 26.60 系 / 仕様参照：TerraFirmaCraft Java 1.21.1-4.2.16
> 文書版：0.1.0（開発中） / 更新日：2026-11-29

この説明書は、初めて遊ぶ人が導入から序盤、採集、加工、農業、食品保存、畜産、UI、トラブル対応まで理解できることを目標にしたプレイヤー向けガイドです。

## 最初に読む重要事項

TFC-Bedrookは開発中です。説明書では状態を次のように区別します。
- **実装あり**：リポジトリに処理やデータがある。実機で完全動作する保証ではありません。
- **一部実装**：一部のアイテム・レシピ・種・動物・操作だけが対象です。
- **検証待ち／未実装**：ゲーム内で利用可能とは限りません。

GitHub Actionsのテスト成功はコードやデータの自動検査結果であり、Bedrock実機での表示・操作・ワールド生成・マルチプレイの保証ではありません。Java版の仕様とBedrookで実装済みの仕様も区別します。

## 1. ゲームの基本

TFC-Bedrookは、Minecraft Bedrock向けにTerraFirmaCraftのサバイバル体験を再構成するアドオンです。採集、素材加工、温度、食料、気候、土壌、動物などの工程を重視します。

基本方針：
- 強い道具をすぐ作らず、素材を集めて段階的に加工する。
- 食料は種類・栄養・鮮度を意識する。
- 作物は気温・水分・土壌養分に左右される。
- 金属は鉱石の採集だけでなく、加熱・溶解・鋳造・鍛造を経る。
- 動物は種ごとに生態・餌・繁殖・産出条件が異なる。
- 独自地形生成は最終開発工程。現状のワールドが完成TFC地形とは限りません。

## 2. 導入とバックアップ

リポジトリにはBehavior Pack（BP）とResource Pack（RP）の開発ソースがあります。ソースコードのフォルダを、そのまま完成済みアドオンとしてインポートできるとは限りません。配布用.mcaddon/.mcpackの作成と実機検証が必要です。

- BP：ゲーム処理、アイテム・ブロック・Entity、Script API。
- RP：テクスチャ、モデル、表示名など。
- BPとRPは同じリリース版を使用してください。

配布版が公開された後の基本手順：
1. 配布元から同じバージョンのパッケージを取得する。
2. .mcaddonまたは.mcpackをMinecraftで開き、インポート完了を確認する。
3. 新規ワールドを作成する。
4. ワールド設定のビヘイビアーパックでBPを有効にする。
5. リソースパックでも対応RPを有効にする。
6. リリースノートに実験機能の指定があれば、その指定に従う。
7. 新規ワールドで動作を確認する。

既存ワールドで試す場合は必ず複製・バックアップしてください。アドオンの追加削除やブロックID変更で既存チャンクに影響することがあります。大きな更新は新規ワールドでの検証を推奨します。

## 3. 操作とUI

現在の開発コードには、メインメニューを開くScript Eventの入口があります。開発用の呼び出しは次のとおりです。

```mcfunction
/scriptevent tfc:menu
```

これは開発用入口です。一般配布版で別の開き方が指定された場合は、配布版の説明を優先してください。

メニュー項目の設計：
- フィールドガイド：序盤、地質、金属、農業、動物、食品保存など。
- プレイヤー情報：季節、推定気温、水分、5系統の栄養、食品鮮度。
- システム一覧：実装概要と制限。
- 食品鮮度一覧：インベントリ内食品の鮮度確認。
- 閉じる：メニューを閉じる。

「使用」は対象アイテムを手に持ち、対象ブロックやEntityに使用操作を行うことです。「スニーク＋使用」はスニーク状態で使用します。端末によってボタン表記が異なる場合はゲーム内表示を優先してください。

## 4. 序盤攻略

以下は現在の初期実装をもとにした進行目安です。Java版TFCの全進行を移植済みという意味ではありません。

1. **初期素材を集める**：火打石、石片、棒、粘土などを確保します。
2. **ナッピングする**：火打石を使うと5×5の成形UIが開く初期処理があります。表示されたマスを選んで形を作ります。
3. **粘土を成形する**：粘土玉を持ってスニーク＋使用すると成形UIを開く処理があります。土器・鋳型・るつぼなどを作る初期ルートがあります。
4. **焼成する**：未焼成品をPit Kilnで焼き、焼成済み容器・鋳型を用意します。
5. **食料を確保する**：焚き火で調理し、鮮度と保存方法を意識します。
6. **鉱石を調べる**：地質調査具で周囲の鉱石を調べる初期機能があります。現状はTFC独自の鉱脈生成ではありません。
7. **金属加工へ進む**：るつぼ、鋳型、金床などを使う初期工程を進めます。
8. **農業と保存食を整える**：種を植え、土壌条件を確認し、乾燥・塩漬け・燻製を利用します。

## 5. 採集とナッピング

ナッピングは石や粘土をマス目状に加工する仕組みです。現在のBedrookには火打石から5×5の石片成形UIを開く初期処理と、粘土玉から容器・鋳型・るつぼを作る成形UIがあります。

未完了：Java版TFCの全形状・全アイテム・全素材、道具の完全な耐久・品質・重量・サイズ、全採集物と地質・気候の連動。

| 素材 | 主な用途 |
|---|---|
| 火打石 | ナッピング開始・石片加工 |
| 石片 | 初期道具素材 |
| 粘土 | 土器・鋳型・るつぼの成形 |
| 棒・糸 | 道具・設備素材 |
| 銅鉱石・錫鉱石 | 初期金属加工 |

## 6. 陶器と焼成

基本工程：粘土を集める → 成形して未焼成品を作る → Pit Kilnへ配置 → 燃料を用意して焼成 → 焼成済み品を取り出す。

| 陶器 | 用途 |
|---|---|
| 土器 | 液体・食品工程の容器 |
| 水入り土器 | 一部の加工素材 |
| 塩水入り土器 | 塩の回収工程 |
| インゴット鋳型 | 溶融金属の鋳造 |
| るつぼ | 金属の溶解・合金化 |

容器の容量、液体挙動、耐熱性などはJava版と同一とは限りません。

## 7. 焚き火と温度

対応設備に燃料を投入し、設備の状態表示で温度・燃焼状態を確認します。燃料が尽きると加熱が止まり、冷却へ移ります。加工対象には必要温度が設定され、温度不足では加工できません。

- 焚き火：調理、食品加工、一部加熱工程。
- Pit Kiln：土器、鋳型、るつぼなどの焼成。
- 燻製設備：隣接する燃焼中の焚き火（初期条件80°C以上）と落ち葉を使う処理があります。

現在の熱モデルは初期実装です。Java版の熱容量・熱伝達・雨・風・送風・全設備特性を完全再現したものではありません。

## 8. 鉱石と地質調査

地質調査具を岩石に使用すると、周辺9×9×5ブロックの範囲にあるバニラ鉱石を調査し、検出数や量の目安をUI表示する初期実装があります。

現状の制限：TFC独自の岩石層・鉱脈分布・鉱石品位・深度別生成は完成していません。独自地形・鉱脈生成は後工程です。現行の地質調査具をJava版Prospector's Pickと同じ挙動だと考えないでください。

## 9. 金属加工

初期の金属加工は銅・錫・青銅を中心とします。鉱石などの素材を用意し、焼成済みのるつぼ・鋳型で溶解や鋳造を行い、冷却後に金床で成形する流れです。

初期青銅UIの登録値：銅88〜92%、錫8〜12%、目安温度950°C以上、焼成済み鋳型を使用。これはBedrookの初期設定値であり、Java版の全合金仕様を意味しません。

現行の初期処理には銅・錫・青銅の鋳造や板材成形などがあります。全金属Tier、鋼・黒鋼・赤鋼・青鋼、全鍛造アクション、溶接などは完全実装済みではありません。

## 10. 農業

基本工程：種を集める → 耕作土を用意 → 種を植える → 気温・水分・NPKを整える → 成熟後に収穫。

作物プロファイルには最低・最高気温、水分、窒素（N）・リン（P）・カリウム（K）、支柱や水辺などの追加条件があります。条件が合わないと成長が遅れたり停止したりします。

データ上の作物プロファイルは29種：小麦、トウモロコシ、ジャガイモ、大麦、オーツ麦、ライ麦、ビーツ、キャベツ、ニンジン、ニンニク、タマネギ、カボチャ、レンズ豆、大豆、落花生、米、キャッサバ、インゲン、パンプキン、メロン、トマト、赤パプリカ、黄パプリカ、アルファルファ、カノーラ、ラディッシュ、サトウキビ、ジュート、パピルス。

プロファイル登録数は、29種すべての種アイテム・作物ブロック・収穫物・テクスチャが完成したという意味ではありません。各種のゲーム内登録と実機動作は個別確認が必要です。

| 作物 | 特殊条件・挙動（データ上の定義） |
|---|---|
| 米 | 淡水条件 |
| トウモロコシ | 2ブロック高 |
| インゲン・トマト | 支柱（トレリス） |
| カボチャ・メロン | 成熟後に実ブロックを広げる |
| ピーマン | 成熟後に繰り返し収穫 |
| サトウキビ・ジュート・パピルス | 2ブロック高 |
| アルファルファ・カノーラ・ラディッシュ | 土壌養分を補う被覆作物として扱う |

NPKは窒素・リン・カリウムです。作物は養分を消費し、作物によって土壌への戻し方も異なります。堆肥・木灰などの初期肥料ルートがありますが、Java版の全肥料と数値を完全再現したものではありません。

## 11. 食品・栄養・水分・腐敗

栄養表示は5系統です。
| 栄養 | 食品の例 |
|---|---|
| 穀物 | 穀物・パンなど |
| 果物 | 果物類 |
| 野菜 | 野菜・根菜など |
| タンパク質 | 肉・豆類など |
| 乳製品 | 牛乳など |

食品は時間経過で鮮度が下がります。現在の表示区分は、新鮮75〜100%、劣化中40〜74%、腐敗間近1〜39%、腐敗0%です。鮮度0で腐敗食品へ変換する処理があります。

メインメニューの食品鮮度一覧では、対象食品をスロット単位で確認する設計です。同じ種類でも別スタックなら鮮度が異なる場合があります。インベントリ移動・分割・統合を含む実機確認は継続課題です。

水分はプレイヤー情報に表示され、時間経過で減少する実装があります。飲料・回復方法の全種類は開発中です。腐敗食品を通常の食料として食べることは推奨しません。

## 12. 食品保存

- **乾燥棚**：棒6本と糸1本から作る初期ルートがあります。肉・果物・野菜などを乾燥するレシピが登録されています。
- **塩**：海洋Biomeの水源から土器で海水を採り、焚き火で煮詰めて塩を回収する初期ルートがあります。
- **塩漬け**：乾燥棚で生肉と塩を組み合わせる初期レシピがあります。
- **燻製**：燃焼中の焚き火（初期条件80°C以上）と落ち葉を使う燻製処理があります。
- **封印**：粘土の封印具を対応容器に使い、封印中の腐敗速度を半分にする初期処理があります。開封すると解除されます。

未完了の保存工程：樽での塩水浸漬・酢漬け、漬物、瓶詰め、ジャム、乳製品の加工・保存、Java版全レシピと保存倍率、容器の液体容量や密封条件の完全再現。

## 13. 動物と畜産

Java版TFC 1.21.xの公式動物ロスター78種を基準にBedrook側の登録・実装状況を追跡しています。ただし、ロスター登録とゲーム内完全再現は別です。現在は一部の独自動物処理と、牛・羊・ニワトリなど既存Entityを利用する処理があります。全78種の専用Entity・モデル・AI・自然スポーンは完成していません。

一部の動物には空腹・渇き・健康・年齢・繁殖状態を管理する仕組みがあります。乳・羊毛・卵などの産出処理も一部ありますが、対象種、産出間隔、巣箱、孵化、個体状態の完全接続は開発中です。

Java版1.21.xのServerConfig既定値はBedrook調整の参照基準です。たとえば牛は成熟192日・妊娠58日・産乳間隔24時間という値が監査資料にあります。これはJava版の既定値であり、Bedrook実機での確定動作値ではありません。

未完了：78種の専用Entity・モデル・テクスチャ、種別の生息環境・餌・AI、捕食と被食、繁殖・妊娠・出産・卵・孵化、乳・羊毛などの産出、老齢・寿命・死亡、再参加後の状態復元。

## 15. トラブル対応

**メニューが開かない**：BPが有効か、RPも有効か、Script API依存関係が読み込まれているか確認し、ワールドを保存して再起動します。開発版ではScript Eventの実行エラーも確認します。

**アイテムが見えない・名前が出ない**：BP/RP両方の有効状態、バージョン一致、ID競合、リソース読み込みエラーを確認します。

**設備が加工しない**：設備の種類、入力素材、燃料、必要温度、焼成済み鋳型・容器、水冷が必要な場合の水源を確認します。

**作物が成長しない**：温度、水分、NPK、淡水や支柱などの特殊条件を確認します。プロファイルがあるだけでゲーム内作物として完成しているとは限りません。

**食品が腐敗する**：鮮度一覧を確認し、乾燥・塩漬け・燻製・対応容器の封印を利用します。保存食も永久保存ではありません。

**更新後にワールドがおかしい**：バックアップへ戻し、新規ワールドでも再現するか確認します。BP/RPの版を揃え、Content Logを保存し、発生手順・端末・Bedrock版・アドオン版を記録します。

## 16. 未実装・検証待ち

次の項目は、設計やデータが存在しても完成機能として扱いません。
- TFC同等の大陸・山脈・谷・火山・海洋・河川を含む独自地形生成。
- 地形と連動した岩石層・鉱脈・鉱石品位。
- 全TFCアイテム・ブロック・レシピ。
- 全金属Tierと鋼・黒鋼・赤鋼・青鋼までの全加工。
- 動物78種の専用Entity・AI・生息条件・繁殖・産出。
- 全食品の栄養・鮮度・腐敗・調理・保存。
- 樽・瓶詰め・漬物・酢漬け・乳製品の完全工程。
- 革加工、ガラス加工、製紙、釣り、機械動力、ポンプなどの全Advanced Mechanics。
- マルチプレイ状態同期と負荷検証。
- iPad/iPhone/Switch 2を含む端末別実機試験。

機能追加後はコード・自動テスト・実機検証を分けて確認し、実機未確認を完成扱いしないでください。

## 17. 用語集

| 用語 | 意味 |
|---|---|
| BP | Behavior Pack。ゲーム処理・アイテム・ブロック・Entityを定義 |
| RP | Resource Pack。テクスチャ・モデル・表示名などを定義 |
| ナッピング | 石や粘土をマス目状に成形する加工 |
| Pit Kiln | 陶器・鋳型などを焼成する設備 |
| Crucible | 金属を溶かするつぼ |
| Anvil | 金属を鍛造・成形する金床 |
| Alloy | 合金 |
| NPK | 窒素・リン・カリウム。植物の主要養分 |
| Freshness | 食品の鮮度 |
| Entity | 動物などのゲーム内存在 |
| Dynamic Property | プレイヤーやワールドに保存する追加データ |
| CI | GitHub Actionsなどによる自動検証 |
| 実機検証 | Minecraftを端末で起動して確認する試験 |
