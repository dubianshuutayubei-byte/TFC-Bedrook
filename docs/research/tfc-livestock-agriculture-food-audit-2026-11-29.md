# TFC 1.21.1 畜産・農業・食品保存 実装監査

更新: 2026-11-29
基準: TerraFirmaCraft NeoForge 1.21.1-4.2.16 と公式 Field Guide。Bedrock 26.60 の実機検証は別判定とする。

## 1. 動物 78 種

### 登録・接続済みの範囲
- Java 1.21.1 の公式ロスター 78 種を登録。
- 78 種すべてに Bedrock の Entity またはバニラ Entity アダプター、クライアント定義、スポーンルール、共有状態プロファイルを用意。
- 公式スポーン配置 78 件を登録（地上 48、水中 29、制限なし 1）。
- 捕食・被食の共有 AI と一部種固有挙動（アルマジロ、バイソン、ヒョウアザラシ、池のカメ、淡水魚群）を実装。

### 完了扱いにしない範囲
- fauna-runtime-coverage.json の remainingSpeciesSpecificWork に残る 55 種は、専用形状・テクスチャ、厳密な生息条件、食性、AI、繁殖・産出などの種別固有作業が残る。
- 新規 15 種は類似種の仮形状・粗いスポーン定義を含むため、登録済みを完全再現済みと同義にしない。
- ラクダの地下水条件は公式値を記録済みだが、環境サンプラーから実測値を渡す接続が未完了。
- 実機での自然スポーン、捕獲、繁殖、再参加後の状態復元は未確認。

## 2. 農業・食品

### 既存実装
- 29 作物の気温・水分・N/P/K要求と土壌影響を個別定義。
- 米の水辺条件、トウモロコシ等の二段ブロック、支柱作物、カボチャ・メロンの果実拡散、ピーマンの段階収穫を実装。
- 土壌水分、肥沃度、肥料、作物成長、収穫品質のランタイム接続あり。
- 食品は5栄養カテゴリ、鮮度、温度依存腐敗、摂取時の栄養・水分反映を実装。
- 乾燥、塩漬け、燻製の加工レシピと保存プロファイルを登録。
- インベントリ内鮮度は ItemStack Lore に保持する方式。スタック分割・統合・移動と実機挙動は要確認。

### 残作業
- 樽・密封容器を使う漬物、酢漬け、塩水浸漬など、Field Guide の保存工程を個別に照合・実装する。
- 乳製品、チーズ、バター等の加工、食品カテゴリ別の完全な料理レシピを追加する。
- 作物別の乾燥出力を汎用「干し野菜」に集約している箇所を、公式工程・個別アイテム仕様と照合する。
- 種子・収穫物・食品プロファイルの全 ID 接続と栄養値は、Java 公式値とBedrook仮バランス値を明確に分離して検証する。
- 腐敗・保存・容器・スタック移動は Bedrock 26.60 実機で検証する。

## 判定

「登録」「静的検査」「ランタイム接続」「実機確認」を別々に扱う。CI成功はJSON/構文/自動テストの成功であり、Minecraft内での完全動作保証ではない。
