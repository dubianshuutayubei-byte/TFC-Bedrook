# TFC-Bedrook 5工程統合監査（2026-11-29）

対象: Bedrock 26.60 / TFC Java 1.21.1-4.2.16 を基準にした実装監査。地形生成は対象外（最後に実施）。

## 1. 78種の動物AI・生態・食性

- 公式対象78種のEntity・Client Entity・Spawn Ruleの登録基盤を確認。
- 55種のカスタムEntity scaffoldと78種のruntime state trackingを確認。
- 捕食関係データのID妥当性・重複・逆引き整合性テストを追加。
- 既存AIは捕食者共通ターゲット、被食者の回避、魚類群、両生類移動などのアーキタイプ単位が中心。
- 55種の固有モデル・固有AI・正確な食性・Java Brain相当は未完了。推測した餌を公式仕様として扱わない。

## 2. 家畜の種別固有繁殖・産出・成長

- official-animal-lifecycle.json の18種のライフサイクル設定をruntime ANIMAL_PROFILESとの接続テスト対象に追加。
- 成熟・妊娠・子数・使用回数・乳/羊毛/卵のクールダウンを中央定義から参照する既存実装を維持。
- ニワトリ・アヒル・ウズラの巣箱/孵化、ウシ・ヤギの乳、アルパカ・ジャコウウシ・フタコブラクダの羊毛、ヤクの乳、ラクダ類の繁殖を監査対象に含めた。
- ネコ・イヌ・ラクダ2種の専用AI/Bedrock実機動作、餌タグ完全一致、出産/産出の永続化・再参加確認は未完了。

## 3. 魚類の捕獲・放流・飼育・スポーン

- Java魚類16種のうち、サケ以外のカスタム淡水魚15種に minecraft:bucketable が登録されていることを追加テスト。
- 15種の水中移動・水中呼吸・水生familyもテスト対象に追加。
- サケはバニラEntity adapterとして扱い、重複したカスタムEntityを作らないことを検査。
- バケツによる捕獲/放流の実機挙動、魚の個体データ保持、魚種別水質・水深・温度スポーン精度は未確認。

## 4. 食品・農業・加工工程

- 34食品プロファイルの腐敗速度とruntime FOOD_DECAY_PROFILES の完全一致テストを追加。
- 作物の温度・水分・養分・収穫・種子、食品摂取、鮮度、乾燥・塩漬け・燻製、石臼/パン、設備加工の既存テスト群を維持。
- 食品のスタック分割/統合、Lore/Dynamic Propertyの保存、マルチプレイ同期、燻製の実機保存期間は未確認。栄養・腐敗速度はBedrook仮バランス値でありTFC公式値ではない。

## 5. 全アイテム・ブロック・レシピ登録監査

- 既存テストで登録済みItem/Block IDの重複、カタログ整合、ブロック設置アイテム、加工レシピの入出力ID、設備UI接続を検査。
- 追加テストで全Itemアイコンと全Block material textureがResource Pack atlasに存在するか確認。
- 現在の登録規模は監査時点でItem 110、Block 14。これはTFC全公式アイテム/ブロックの完全移植ではない。
- 未登録の公式アイテム/ブロック、専用テクスチャの品質、レシピ全量のJava版一致、実機UI操作は残作業。
