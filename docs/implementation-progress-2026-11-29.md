## 追加修正：Java版1.21.xの繁殖・老齢化仕様へ再同期

公式ソース `TFCAnimalProperties.java` と `ServerConfig.java` を再確認し、前回の繁殖回数実装にあった差を修正。

- 交配成立時、妊娠するメスは受精状態になる。繁殖使用回数を5加算するのは相手のオスのみ（公式 `onFertilized` の `male.addUses(5)` に一致）。
- 老齢化予定日は使用回数が設定値と同じになった時点ではなく、設定値を超えた後に設定する（公式 `getUses() > getUsesToElderly()` に一致）。
- 乳・羊毛・卵の産出についても同じ「しきい値を超えた後」の老齢化判定に統一。
- しきい値と同じ使用回数では、老齢化予定日前の産出を許可する。
- 日本語説明書の誤った「両親両方に加算」という説明を訂正。
- テストを更新し、オスのみ5回加算、しきい値到達時、しきい値超過時、産出・産卵の境界を検査。

## 追加修正：なつき度減衰の公式タイミング

- TFC Java 1.21.xの `tickAnimalData` を確認。なつき度が30%未満の場合、最後の給餌から2日を超えてから減衰を開始する。
- 減衰量は1日あたり2ポイント（0.02）。経過した整数日分だけ適用し、日未満の端数時間を次回へ持ち越す。
- 旧実装は1日経過後から減衰し、端数日数をそのまま減算していたため修正。
- 産出回数の老齢化判定も「しきい値以上」ではなく「しきい値超過」に統一。
- テストに2日ちょうどでは減衰しないこと、2.5日で2ポイント減衰すること、端数時間の保持を追加。

**公式参照:** [TFCAnimalProperties.java](https://github.com/TerraFirmaCraft/TerraFirmaCraft/blob/1.21.x/src/main/java/net/dries007/tfc/common/entities/livestock/TFCAnimalProperties.java)
